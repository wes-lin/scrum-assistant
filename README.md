# Scrum Assistant

这是一个无需构建工具的 Manifest V3 浏览器插件，适用于 Chrome、Edge 等 Chromium 浏览器。

## 功能

1. 在配置的 GitLab 地址中，把符合任务 / Bug 正则规则的文字转换为禅道链接。GitLab 的 SPA 页面和后续加载的评论也会自动处理。
2. 在配置的禅道地址的“创建/新建分支”页面，在 `branchName` 输入框旁增加分支类型选择，并固定按 `类型/名称` 生成分支名称；支持普通 iframe 和 `about:blank` 对话框。
3. 所有地址、正则、链接模板和分支类型都可以在插件设置页修改，配置保存在浏览器本地。

## 安装

1. 打开浏览器扩展管理页，开启“开发者模式”。
2. 选择“加载已解压的扩展”，选中本目录 `scrum-assistant`。
3. 点击插件图标，打开设置页，填写 GitLab 和禅道地址后保存。

## 规则配置

规则使用 JavaScript 正则表达式，且第一个捕获组必须是 ID。默认值为：

- 任务：`(?:任务|task)[\\s#:/-]*(\\d+)`
- Bug：`(?:缺陷|bug)[\\s#:/-]*(\\d+)`

如果团队使用 `TASK-123` 和 `BUG-456`，可以改成：

- `TASK-(\\d+)`
- `BUG-(\\d+)`

链接模板中的 `{id}` 会替换为捕获到的 ID。默认模板适用于禅道标准路由：

- 任务：`/zentao/task-view-{id}.html`
- Bug：`/zentao/bug-view-{id}.html`

如果禅道部署在 `https://intranet/zentao`，插件会自动把上述路径拼接到 `/zentao` 下。

## 分支名称

默认分支类型为 `feature`、`release`、`hotfix`，分支名称格式固定为 `类型/名称`。例如原名称为 `task-1498`，选择 `feature` 后会生成 `feature/task-1498`。选择“不创建类型”则保留原名称 `task-1498`。分支类型的提交值和显示名称可以在设置页维护。

## 注意

插件使用 `http://*/*` 和 `https://*/*` 内容脚本匹配，是为了支持未预先知道域名的内网部署；实际处理页面前仍会严格比对设置中的 GitLab / 禅道地址。修改设置后请刷新已经打开的页面。
